# 변경 기록

운영 배포 뒤에 추가한 기능, 개선한 점, 고친 버그를 배포 단위로 남긴다. 시각은 운영에 배포한 한국 시간이다. 배포마다 GitHub Releases에도 커밋 목록이 남는다.

- **기능**: 새로 생긴 기능
- **개선**: 있던 기능을 더 쓰기 좋게 바꾼 것
- **버그**: 잘못 동작하던 것을 고친 것

## 배포 대기
