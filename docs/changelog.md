# 변경 기록

운영 배포 뒤에 추가한 기능, 개선, 버그 수정을 배포 단위로 남긴다. 시각은 한국 시간 기준 운영 배포 시각이다. 배포마다 GitHub Releases에도 커밋 목록이 남는다.

- **기능**: 새로 생긴 기능
- **개선**: 있던 기능을 더 쓰기 좋게 바꾼 것
- **버그**: 잘못 동작하던 것을 고친 것

## 배포 대기

| --- | --- | --- | --- |
| 버그 | 소집일을 오늘 이후 날짜로 넣지 못하게 막음 | 한 직원이 소집일을 미래(12월 18일)로 잘못 넣어 아직 복무 전으로 처리됐다. 식당지원표 선택 목록에서 빠지고, 그 전까지 잡혀 있던 식당지원 일정이 자동으로 지워졌다 | 미래 소집일은 저장되지 않고 이유를 안내한다. 같은 상황을 재현하는 테스트를 추가했다 |
| 개선 | 사진 올리기 전 브라우저에서 1600px로 줄이고, 저장 중 전체 화면 안내 표시 | 휴대폰 사진(3–12MB)을 올리는 데 몇 초씩 걸리는데 아무 표시가 없어, 멈춘 줄 알고 다른 화면을 누르는 사례가 있었다 | 12MB 사진이 1MB 아래로 줄어 전송된다. 저장이 끝날 때까지 "잠시만 기다려주세요"가 보인다 |
