# 변경 기록

운영 배포 뒤에 추가한 기능, 개선한 점, 고친 버그를 배포 단위로 남긴다. 시각은 운영에 배포한 한국 시간이다. 배포마다 GitHub Releases에도 커밋 목록이 남는다.

- **기능**: 새로 생긴 기능
- **개선**: 있던 기능을 더 쓰기 좋게 바꾼 것
- **버그**: 잘못 동작하던 것을 고친 것

## 배포 대기

| 구분 | 내용 | 배경 | 변경 사항 |
| --- | --- | --- | --- |
| 개선 | 직군 변경을 두 번 확인 | 직원 상세의 근무 정보에서 선택 칸을 잘못 건드려도 저장 버튼 한 번에 직군이 바뀌고, 나눔가게나 식당지원에서 자동으로 빠질 수 있었다 | 근무 정보에는 지금 직군만 보여 주고, "직군 변경"을 눌러야 직군을 고르는 창이 열린다. 고른 직군 때문에 빠지는 활동이 있으면 "직군 변경 시 자동 탈퇴" 경고를 한 번 더 띄워 확인을 받는다 |
| 버그 | 식당지원표에서 직원을 체크해도 인원 수가 그대로임 | 관리자가 2명을 체크해도 저장하기 전까지 "0 / 2명"으로 남아, 제대로 골랐는지 알 수 없었다 | 체크할 때마다 인원 수와 이름 칩을 바로 다시 그린다. 인원이 모자라거나 넘치면 빨간색으로, 휴가와 겹친 사람은 "휴가 겹침"으로 바로 보여준다 |
| 버그 | 소집일에 미래 날짜를 넣지 못하게 막음 | 한 직원이 소집일을 12월 18일로 잘못 넣는 바람에 아직 복무 전인 사람으로 처리됐다. 식당지원표 선택 목록에서 사라졌고, 그날 전까지 잡혀 있던 식당지원 일정도 자동으로 지워졌다 | 오늘 이후 날짜는 저장되지 않고 실제 소집일을 넣으라고 안내한다. 날짜 선택 칸에서도 미래 날짜를 고를 수 없게 했다. 같은 상황을 재현하는 테스트를 넣었다 |
| 개선 | 사진 저장 속도 개선과 저장 중 안내 | 휴대폰 사진(3–12MB)을 올리는 데 몇 초씩 걸리는데 화면에 아무 표시가 없어서, 멈춘 줄 알고 다른 화면을 누르는 경우가 있었다 | 올리기 전에 브라우저에서 사진을 1600px로 줄여 보내도록 해 12MB 사진도 1MB 아래로 전송된다. 저장이 끝날 때까지 화면 전체에 "잠시만 기다려주세요"를 띄우고, 고른 사진을 미리 보여준다 |
